1. **Pick a department** below that matches the role you'd otherwise hire for.
2. **Open the install link.** Each one takes you to the official GitHub repo or Claude plugin page.
3. **Install the skill** in Claude Code or Claude Desktop (most are one command or one click).
4. **Delegate.** Treat each skill like a team member: give it a clear brief and let it work.
