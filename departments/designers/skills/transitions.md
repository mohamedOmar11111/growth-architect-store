# Transitions

**What it does:** Implements smooth, performant page transitions and micro-animations using modern techniques (Framer Motion, View Transitions API, CSS). Elevates product feel from "web app" to "native-quality experience."

**Install:** [github.com/Jakubantalik/transitions.dev](https://github.com/Jakubantalik/transitions.dev)

**Best for:**
- Adding polish to page navigation
- Micro-interactions on buttons, cards, modals
- Reducing perceived latency during transitions
