# Context7

**What it does:** Automatically fetches current, version-specific documentation for any library or framework and injects it into Claude's context. Eliminates outdated API answers and hallucinated method signatures.

**Install:** [github.com/upstash/context7](https://github.com/upstash/context7)

**Best for:**
- Working with rapidly changing libraries
- Avoiding deprecated API calls
- Getting accurate code examples for any package
