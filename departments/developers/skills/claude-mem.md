# Claude-Mem

**What it does:** Provides persistent memory across Claude sessions. Stores project context, decisions, preferences, and history so Claude doesn't start from zero every conversation. Uses local file storage.

**Install:** [github.com/thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)

**Best for:**
- Long-running projects with multiple sessions
- Maintaining context across different chats
- Team knowledge retention
