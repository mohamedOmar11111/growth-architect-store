## Adding Individual Skills

To add skills from the bundle to this directory:

1. Browse the [marketingskills repo](https://github.com/coreyhaines31/marketingskills)
2. For each skill you want, create a file in `skills/` using the template
3. Update this README table
4. Run validation

**Example:**
```bash
cp ../../templates/skill-template.md skills/seo-audit.md
# Edit frontmatter and body
# Add row to table below
```
